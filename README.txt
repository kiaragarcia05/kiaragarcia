KIARA PORTFOLIO — HOW TO PUBLISH

1. Unzip the folder.
2. Open index.html in your browser.
3. Upload index.html, homework.html, projects.html, about.html, style.css, and the assets folder into your existing GitHub repository.
4. GitHub Pages will publish the updated site.
5. IMPORTANT: Brightspace links may require a login. Download your artwork and reflections, place them in an assets/homework folder, and change the links in homework.html to those local files. This is necessary to show the actual work publicly.
6. The original homepage selfie and creative statement have not been copied because your GitHub source files were not provided. Preserve them manually if needed.
7. Check image licensing before publishing the reference illustration publicly.
